# 星座体规范（Selagrafi · 星座式排布）

> 与「星轨体」并列的第二套书写排布规范。二者**共用同一套星符**，仅排布规则不同。
> 版本：v1.1 ｜ 状态：生效中（`文字.md` §十 已建立索引；完整规则以本文件为准）
>
> **⚠️ 机器校验**：本文件中的 `0.42` / `0.27` / `26` / `17` / `≤ 4 词` / `50–90°` / `120px`
> 已被 `数据/校验.ps1` 第 16 项锚定。**改动这些数值时必须同步 `数据/lumia.json` 的
> `script.constellation`**，否则校验会直接 FAIL——这是为了防止规范与数据源悄悄漂移。

---

## 一、基本对应

星座体把文本还原成天空：

| 文本单位 | 天文对应 | Lumia 词 |
| --- | --- | --- |
| 词 | 星 | `sela` |
| 句 | **星座** | — |
| 段（2–4 句） | **星系** | `gala` |
| 篇 | **星海** | — |

**一句话 = 一个星座。**

---

## 二、三级视觉层级

| 层级 | 单位 | 连接方式 | 线条 |
| --- | --- | --- | --- |
| 星座 | 一句 | **句轨**（实线） | `#6fd6ff` @ 0.34 |
| 星系 | 一段 | **弧轨**（虚线弧） | `#6fd6ff` @ 0.27 |
| 星海 | 全篇 | 不连，仅留白 | — |

> **核心原则：真实星空中，星座之间本就没有连线。**
> 所以句间连接一律弱于句内——这是星座体区别于「连写」的根本立场。

## 三、节点规则

现代词类判定依据 `数据/lumia.json` 的 `cat` / `pos` 字段。

| 类型 | 判定 | 缩放 | 不透明度 | 说明 |
| --- | --- | --- | --- | --- |
| **主星** | 代 / 名 / 动 / 形 / 数 | 0.42 | 1.0 | 完整星符，保留星点 |
| **伴星** | 助 / 连 / 介 / 疑 | 0.27 | 0.60 | 缩小压暗，表语法从属 |
| **双星** | 专名（`na` 之后） | 主星 + 伴点 | — | 主星旁加一颗 `#ffd166` 伴点，短线相连 |

> 伴星不改变字形本身——`ku`（点+下横）的点是字形构成，不是星点点缀，予以保留。

### 星位光晕 ★

每个节点外围加一个极淡的圆环，标记「此处是一颗星」：

| 类型 | 光晕半径 | 样式 |
| --- | --- | --- |
| 主星 | **26** | `fill:none; stroke:#6fd6ff; stroke-width:.5; opacity:.13` |
| 伴星 | **17** | 同上 |

**光晕半径必须等于句轨的断口**——连线恰好停在光晕边缘，星与线的关系一目了然。

> 这一条解决一个具体问题：`li`（短横）、`e`（短竖）、`en`（双横）等伴星的**字形本身就是线段**。
> 没有光晕时，读者会把它与句轨混淆，感觉线「断了一下」。

### 附着物：数词与专名 ★

Lumia 的**每个数词都一词双义**（数值义 + 实义），**专名则没有星符**。
两者都用 `cat = num` 的「星数」（100 格）与「音节符串」（100 格，见 `音节图.svg`）拼出，
但它们**不是句轨上的普通节点**。

#### 数词：双义决定身份

| 用法 | 判定 | 身份 | cell | 与句轨的关系 |
| --- | --- | --- | --- | --- |
| **数词 · 实义** | 自己作句子成分（主语 / 宾语） | **主干节点** | **44** | 坐在句轨上，是星座的骨架 |
| **数词 · 数值** | 紧贴名词作修饰语（`dua luna`） | **卫星** | **28** | 挂在名词旁侧，**不落句轨** |

> 例：`tia li oba.` 中 `tia` 作主语 → 实义「三体」，是**主干节点**；
> 而 `dua luna` 中 `dua` 修饰 `luna` → 数值义「二」，是**卫星**。

**卫星式附着——地球与月球的关系：**

- **位置**：挂在被修饰星符**旁侧**，**不落在句轨上**。默认方位为与句轨**垂直**的一侧，
  也可按构图自由选取，只须满足：**卫星到句轨的最近距离 ≥ 卫星光晕半径 + 6px**。
- **距离**：卫星中心 = 主星中心 + (主星 cell / 2 + 卫星 cell / 2 + **30**)
- **连线**：一条**较浅的线**——比句轨更细更淡（宽 **0.8**、不透明度 **0.24**；句轨为 0.9 / 0.34）。
  这是「引力」，不是「路径」，必须弱于句轨。

> 卫星的偏心位置让星座从「一条折线」变成「主干 + 绕行天体」——**这是立体感的来源**。

#### 音节符串：多体链

专名（`na` 之后）以音节符串拼写：首节坐句轨的节点位，后续音节沿**垂直于句轨**的方向依次排开，
节间距 **42px**。整串如同一颗**双体 / 多体**（如 `Vega` = `ve` + `ga`）。

- 每节 cell **30**
- 串内以同款「较浅的线」相接
- **附着物不参与句轨主路径**——句轨只连词级节点。
  否则一句话的句轨会被拆成十几个碎节，星座感全毁。

### 统一公式：光晕半径

```
光晕半径 = cell / 2 + 1
```

据此，所有节点的光晕半径自动得出：

| 节点 | cell | 光晕半径 |
| --- | --- | --- |
| 主星 | 50 | **26** |
| 伴星 | 32 | **17** |
| 数词 · 实义（主干） | 44 | 23 |
| 数词 · 数值（卫星） | 28 | 15 |
| 音节符 | 30 | 16 |

> 早先的 `26` / `17` 并非硬编码，而是这个公式的两个特例。

配套示例见 `星座体数字与音节示例.svg`。

## 四、句轨规则

1. 按**语序**依次连接相邻节点，一词一节点。
2. 入点 / 出点沿用星轨体规则：**左入右出**。
3. 句轨是**实线**，宽 0.9，不透明度 0.34——**弱于星符本身**，让视觉重心落在星上。
4. **句轨必须在节点处断开**，断口 = 该节点的**星位光晕半径**（主星 26 / 伴星 17）。
   > 真实星图的连线是**停在星上**的，不是穿过去的。
   > 这一条是星座体与「折线图」最直接的分界。
5. 句轨在节点层**之下**绘制。
6. **短句闭合**（≤ 4 词）：在末星与首星之间补一条**闭合轨**，把整句收成一个封闭图形。
   - 样式：实线，不透明度降至 **0.16**——明显弱于句轨，以免被误读成「还有一个词」。
   - 依据：真实星座多为封闭多边形（猎户座四边形、三角座）；且与「句号」的语义天然呼应。
   - **长句（≥ 5 词）保持开放**：闭合会拉出一个过大的环，反而抢镜。

## 五、标点

| 标点 | 星座体表现 |
| --- | --- |
| **句号** | 末星右下垂一颗**落星**：小点，r=2.5，`#9fb4c8`，无符号 |
| **逗号 / 分句** | 句轨上嵌一颗**节点星**：r=3.5，`#9fb4c8`，不构成词 |
| **问号** | 末星为 `ka`；星座首尾可闭合成环，强调「未定」 |
| **叹号 / 祈愿** | `o` 起首；整座星座半径放大 1.15 倍 |

Lumia 语法本身靠功能词承载疑问、否定、呼格，故标点可视作**冗余提示**，非必需。

### 节点星与落星的区分

| | 位置 | 与句轨的关系 | 尺寸 |
| --- | --- | --- | --- |
| **节点星**（逗号） | 句子内部 | **嵌在句轨上**，句轨从两侧接入 | r=3.5 |
| **落星**（句号） | 末星外侧 | **悬在句轨之外**，不接任何线 | r=2.5 |

> **结论：不需要为落星另设形制。**「嵌在轨上」与「悬在轨外」本身已足够区分，尺寸差只是辅助。

## 六、句间连接（三种模式）★

### 模式 A：游离（默认）

- **适用**：2 句以内，或相邻句语义跳跃大。
- **做法**：不画任何连接线，仅靠留白分组。
- **依据**：真实星座之间没有连线；这是最「忠于天空」的处理。

### 模式 B：弧轨（推荐，2–4 句）

- **做法**：前一句**末星** → 后一句**首星**，连一条**三次贝塞尔弧线**。
- **弧向**：朝下（即阅读推进方向），形似轨道转移段。
- **样式**：虚线 `dasharray 3 6`，宽 1，不透明度 0.27。
- **约束**：弧线不得落在任何节点上；与星座重叠时置于节点层之下。

### 模式 C：星系主轨（5 句以上）

- **做法**：设一条横贯全篇的**主轨**（极缓的弧或直线）。
- **挂接**：每座星座作为整体，以一条短垂线挂在主轨上。
- **样式**：主轨不透明度 0.12；短垂线 0.20。
- **类比**：行星挂在轨道上，星座挂在主轨上。

### 长句分簇（同一句之内）

单句超过 **10** 词时，句轨会拉得过长、失去星座感。此时把该句切成若干**子簇**（每簇 4–6 词）：

- 子簇之间**不画弧轨**——它们仍属同一句
- 子簇**间距 40px**；而**句间留白 ≥ 60px**
- 二者的区分靠**留白大小 + 有无弧轨**双重提示

> 分簇是**版式手段**，不是语法手段：它不改变节点顺序，只把一条长轨折成几段。

## 七、方向与版式

- **版式单位**：每句占一个「星图块」，块与块**纵向排列**。
  > 块的长宽比**不必是正方形**。初稿曾写「横向长条在数学上出不了锐角」，这是**不准确的**——
  > 锐角来自段与段之间的方向突变，宽而矮的图形只要每段足够陡，同样能全是锐角。
  > 但纵向确实不能压得太扁，否则段长趋于水平，方向差自然变小。
- **句内走向**：整体自左向右；**允许节点小幅回折**，上限 **120px**。
- **句间**：由上而下，块间留白 ≥ 60px。
- **一篇之内不混用方向**。
- **点题与句注**：置于左侧标注列，与星图块之间留出 ≥ 40px。

### 竖排模式

**竖排 = 横排版式整体顺时针旋转 90°**。于是：

| | 横排 | 竖排 |
| --- | --- | --- |
| 句内 | 左 → 右 | **上 → 下** |
| 句间 | 上 → 下 | **右 → 左** |
| 入点 / 出点 | 左入右出 | **上入下出** |

除此之外**一切规则不变**——这正是本规范选择「旋转等价」而不是另立一套的理由。

### 内角目标 ★

| 目标 | 说明 |
| --- | --- |
| **50–90°** | 主目标。既有明确的形体感，又不至于尖锐到像闪电 |
| **> 110°** | 全篇超过三个就必须重排——说明纵向被压扁了 |
| **< 40°** | 过尖，形似断裂；用小幅回折来调节，不要靠拉长线段 |

> **经验值（启发式，非硬性）**：纵向可用高度 ≥ 横向跨度的 **0.6 倍** 时最容易出锐角。
> 但真正的机制是**段与段之间的方向突变**——只要每段足够陡，宽而矮的图形也能全是锐角。
> 比例只是最省事的做法，不是充要条件。

### 空间按词数分配 ★

**不要给每个星图块平均分配空间。** 词数差异大时（如 3 词对 7 词），平均分配会让长句挤成一团、
短句空旷无力。

| | 词数 | 建议占地 |
| --- | --- | --- |
| 短句 | 3 | 约 260 × 190 |
| 中句 | 5 | 约 340 × 190 |
| 长句 | 7 | 约 415 × 275 |

**目标：每节点的平均占地面积大致相等**（示例中为 16.5k / 16.2k / 13.0k 像素²）。
初版按块平均分配，导致长句的每节点面积只有短句的 **44%**，读起来明显拥挤。

### 排布必须不规则 ★

> 这是星座体最容易失败的一点。

- 相邻节点的**间距**与**起伏幅度**不得重复。
- **等间距 + 等幅度交替 = 折线图**，不是星座。这是最常见的失败样式。
- 实务参数：间距在 **80–220px** 之间变化；竖向偏移**避免**固定的 ±45px 交替。
- **允许聚星**：两个节点可靠近至 80px，制造疏密对比——真实星座本就有密有疏。

**要成「臂」，不要成「锯齿」**——这才是关键：

| | 做法 | 效果 |
| --- | --- | --- |
| ✅ | 连续 2–3 个节点**同向推进**，构成一条**臂** | 有形体感 |
| ✅ | 用一段**近乎水平的平台段**，或一次**陡升 / 陡降**作转折 | 有节奏 |
| ❌ | **每换一个词就反向一次**（`/\/\/\`） | 无论幅度怎么抖，**仍然是折线图** |

> 单纯"抖坐标"治不好折线图——必须打破"每词必反向"的节奏假设。

## 九、与星轨体的分工

| | 星轨体 | 星座体 |
| --- | --- | --- |
| 定位 | 实用书写 | 艺术排布 |
| 连写 | 追求一笔连写 | **不连写** |
| 方向 | 横向逐词 | 成星座，句间下行 |
| 场景 | 日常书写、文档 | 会徽、海报、星图、Slogan |
| 星符 | 共用 | 共用 |

**星座体不替代星轨体**——它是把同一套星符「摆成天空」的展示规范。
