# Lumia 数字系统（Numerals）

十进制，但**不设「纯数字词」**：每个数词都是一个有实义的内容词，数值义与实义按**位置、语境**判定。0 与 1 直接复用现有词。

## 一、数词表（一词双义）

| 数字 | Lumia | 实义 | 数词义 |
| --- | --- | --- | --- |
| 0 | `vaka` | 虚空、真空、空、无 | 零 |
| 1 | `sola` | 太阳、唯一 | 一 |
| 2 | `dua` | 双、对、成双、孪生 | 二 |
| 3 | `tia` | 群、聚、三角、三体 | 三 |
| 4 | `teta` | 方、十字、四方、四芒 | 四 |
| 5 | `penta` | 手、掌、五芒星 | 五 |
| 6 | `hesa` | 六方、蜂窝、六分 | 六 |
| 7 | `heta` | 周、七曜、一星期 | 七 |
| 8 | `ota` | 八方、八分、八度 | 八 |
| 9 | `enea` | 极多、众多、九重 | 九 |
| 10 | `deka` | 满环、完整周期、圆满 | 十 |
| 100 | `sento` | 星团、众多 | 百 |
| 1000 | `kilo` | 星海、无量、极多 | 千 |

> **语境判定示例**：`sola` 作中心词（主语/宾语）＝太阳；作前置修饰语＝一。
> `mi mira e sola.`＝我看太阳。 · `sola ena`＝一个人 · `mi vira e sola sela.`＝我有一颗恒星。
> 数词一律**前置**（`dua luna` 两个月亮、`ota aka` 八点）；后置的数词是早期写法，已废止。

## 二、组数规则

- 大位在前、小位在后，直接并置（无「和」）。
- 十位以上：`X deka Y`。

| 数字 | Lumia |
| --- | --- |
| 10 | `deka` |
| 11 | `deka sola` |
| 12 | `deka dua` |
| 20 | `dua deka` |
| 21 | `dua deka sola` |
| 42 | `teta deka dua` |
| 100 | `sento` |
| 101 | `sento sola` |
| 256 | `dua sento penta deka hesa` |
| 1000 | `kilo` |
| 2025 | `dua kilo dua deka penta` |
| 10000 | `deka kilo` |
| 100000 | `sento kilo` |
| 1000000 | `kilo kilo` |

> 大数用**复合**（十千/百千/千千），不新造词。书写则按**位值横排**数字符（见《文字》`数字符表.svg`）。

## 三、序数、次数、分数

- 序数 / 次数：都是 `oba` + 数词。`oba dua`＝第二（第二个循环）；`oba tia`＝第三 / 三圈。
  这正是 `oba`（轨道、圆、循环）本义的自然延伸。
- 分数：`X fo Y`（Y 分之 X）。`sola fo dua`＝二分之一。

## 四、「很多 / 全部 / 无穷」

| 概念 | Lumia | 意象 |
| --- | --- | --- |
| 多 | `mola` | 众多 |
| 全部 | `ala` | 一切 |
| 无数/无穷 | `gala` | 星系（星海无垠） |

## 五、示例

| Lumia | 中文 |
| --- | --- |
| `sola` | 太阳 / 一 |
| `mi vira e dua luna.` | 我有两颗卫星。 |
| `Satuna li vira e luna mola.` | 土星有许多卫星。 |
| `komo lo vaka, no enega.` | 宇宙在虚空中，没有能量。 |

## 六、七曜与时刻

### 星期（七曜）

古典七曜只用**肉眼可见的五颗行星 + 日月**，Lumia 现有词表刚好全覆盖：

| 星期 | 天体 | Lumia |
| --- | --- | --- |
| 周日 | 太阳 | `sema na Sola` |
| 周一 | 月亮 | `sema na Luna` |
| 周二 | 火星 | `sema na Masa` |
| 周三 | 水星 | `sema na Mekuria` |
| 周四 | 木星 | `sema na Jupita` |
| 周五 | 金星 | `sema na Venusa` |
| 周六 | 土星 | `sema na Satuna` |

**构词**：`sema`（时间）+ `na` + 天体名（首字母大写，视作专名）——沿用已有的「类属 + `na` + 专名」模式，**不新造词**。

> **地球 `Tera`、天王星 `Urana`、海王星 `Nepuna` 不入七曜**——因为七曜本就只用肉眼可见的行星。

### 小时

同样**不新造词**，直接用现有的 `aka`：

```
一天   = oba（轨道 / 圆 / 一整个循环）
一小时 = aka（这个圆上的一段弧）
```

`aka` 的基元义本就含「**部分**」——弧即圆的一部分。这与 `pela`（过去 = 星轨之尾）、`meta`（未来 = 光锥之前）、`oba`（反复 = 轨道再一圈）是**同一套天体隐喻**。

| Lumia | 中文 |
| --- | --- |
| `ota aka` | 八点（数词前置） |
| `ota aka la, mi vega.` | 八点时我出发。 |
| `sema dama` | 夜晚（黑暗之时） |
