# Lumia 音系（Phonology）

Lumia 的发音追求「英式、简单、悦耳」。规则很少，几分钟即可掌握。

## 一、元音（5 个）

| 字母 | IPA | 英式参考音 | 例词 |
| --- | --- | --- | --- |
| a | /ɑ/ | father、car（非卷舌） | sola /ˈsɒ.lɑ/ |
| e | /ɛ/ | dress、bed | sela /ˈsɛ.lɑ/ |
| i | /i/ | fleece、see | lumia /ˈlu.mi.ɑ/ |
| o | /ɒ/ | lot、hot（英式短 o） | komo /ˈkɒ.mɒ/ |
| u | /u/ | goose、moon | luna /ˈlu.nɑ/ |

- 元音都是**单元音**，无 /ə/、无 /æ/、无 /ʌ/（这些英式常见音在 Lumia 中不出现）。


## 二、辅音（16 个）

| 字母 | IPA | 英式参考音 |
| --- | --- | --- |
| p | /p/ | pen |
| t | /t/ | tea（不送气化不明显，无 /tʃ/ 腭化） |
| k | /k/ | key |
| b | /b/ | boy |
| d | /d/ | day（**无 yod**：du = /du/，不读 /dju/） |
| g | /g/ | go |
| f | /f/ | fat |
| v | /v/ | van |
| s | /s/ | sun（**永远是清 /s/**，不浊化） |
| h | /h/ | hat |
| m | /m/ | man |
| n | /n/ | no |
| l | /l/ | let（清晰 /l/，不软腭化） |
| r | /r/ | **颤/闪音**，如苏格兰或意大利语 r；只出现在元音前 |
| w | /w/ | wet |
| j | /j/ | yes（像「y」，**不是** /dʒ/） |

要点：
- **非卷舌**：`r` 从不作韵尾、从不卷舌，词尾绝不出现 r。
- **无送气对立**：p/t/k 与 b/d/g 的对立是清浊，不靠送气区分。
- **d/t 后跟 u 不发 yod**：`dua` 读 /ˈdu.ɑ/，`tu` 读 /tu/（现代英式口音里 dune/tune 亦可如此）。

## 三、音节结构

```
(C) V (n)
```

- 一个音节 = 可选的一个辅音 + 一个元音，**n 可作音节尾（含词中与词末）**。
- **无辅音丛**、**无双元音**：相邻元音各自成音节（如 `lumia` = lu·mi·a，三音节）。
- 允许的音节尾辅音只有 `n`（如 `en`、`sento`）。

## 四、重音

- **重音永远落在词首音节**。
- 重读表现为音高略升、响度略增，不区分元音长短。

## 五、希腊·拉丁借词的音系适配规则

天文/科幻词来自希腊·拉丁语，进入 Lumia 时必须削成 CV 音节。规则：

1. **删去或调整词尾屈折**：`-us / -a / -ēs / -os` 等。
2. **辅音丛删去其一**（通常保留更「显著」者，或换位成 CV）：`st→s`、`pl→p`、`kr→k`、`tr→t`、`ks→s`。
3. **非 n 的韵尾辅音删除**。
4. **r 只出现在元音前**；借词中处于音节尾或辅音前的 r 删除。

部分借词为**缩合形式**，不完全遵循上述规则；如 `era`（aēr）、`sento`（centum，按英式读音）、`kilo`（khilioi）。

例：

| 源词 | Lumia | 说明 |
| --- | --- | --- |
| stella | **sela**（星） | st→s，去 geminate l |
| sol | **sola**（太阳） | +a |
| luna | **luna**（月亮） | 不变 |
| planētēs | **paneta**（行星） | pl→p，去词尾 |
| kosmos | **komo**（宇宙） | 删 s |
| orbis | **oba**（轨道） | 删 r、去 -is |
| vacuus | **vaka**（虚空） | 缩合 |
| pulsus | **pusa**（脉冲） | 删 l、去 -us |
| mikros | **miko**（小） | kr→k |
| makros | **mako**（大） | kr→k |
| energeia | **enega**（能量） | 删 r、缩 ia |
| aēr | **era**（大气） | 缩合 |

> 专名同样遵循此规则：Saturnus → **Satuna**（土星）、Mercurius → **Mekuria**（水星）。
