# Lumia 音系（Phonology）

Lumia 的发音追求「英式、简单、悦耳」。规则很少，几分钟即可掌握。

## 一、元音（5 个）

| 字母 | IPA | 英式参考音 | 例词 |
| --- | --- | --- | --- |
| a | /ɑ/ | father、car（非卷舌） | sola /ˈsɒ.lɑ/ |
| e | /ɛ/ | dress、bed | sela /ˈsɛ.lɑ/ |
| i | /i/ | fleece、see | lumia /ˈlu.mi.ɑ/ |
| o | /ɒ/ | lot、hot（英式短 o） | komo /ˈkɒ.mɒ/ |
| u | /u/ | goose、moon | luna /ˈlu.nɑ/ |

- 元音都是**单元音**，无 /ə/、无 /æ/、无 /ʌ/（这些英式常见音在 Lumia 中不出现）。


## 二、辅音（16 个）

| 字母 | IPA | 英式参考音 |
| --- | --- | --- |
| p | /p/ | pen |
| t | /t/ | tea（不送气化不明显，无 /tʃ/ 腭化） |
| k | /k/ | key |
| b | /b/ | boy |
| d | /d/ | day（**无 yod**：du = /du/，不读 /dju/） |
| g | /g/ | go |
| f | /f/ | fat |
| v | /v/ | van |
| s | /s/ | sun（**永远是清 /s/**，不浊化） |
| h | /h/ | hat |
| m | /m/ | man |
| n | /n/ | no |
| l | /l/ | let（清晰 /l/，不软腭化） |
| r | /r/ | **颤/闪音**，如苏格兰或意大利语 r；只出现在元音前 |
| w | /w/ | wet |
| j | /j/ | yes（像「y」，**不是** /dʒ/） |

要点：
- **非卷舌**：`r` 从不作韵尾、从不卷舌，词尾绝不出现 r。
- **无送气对立**：p/t/k 与 b/d/g 的对立是清浊，不靠送气区分。
- **d/t 后跟 u 不发 yod**：`dua` 读 /ˈdu.ɑ/，`tu` 读 /tu/（现代英式口音里 dune/tune 亦可如此）。

## 三、音节结构

```
(C) V (n)
```

- 一个音节 = 可选的一个辅音 + 一个元音，**n 可作音节尾（含词中与词末）**。
- **无辅音丛**、**无双元音**：相邻元音各自成音节（如 `lumia` = lu·mi·a，三音节）。
- 允许的音节尾辅音只有 `n`（如 `en`、`sento`）。

## 四、重音

- **重音永远落在词首音节**。
- 重读表现为音高略升、响度略增，不区分元音长短。

## 五、借词的音系适配

Lumia 的音节只有 `(C)V(n)` 一种形状（§三）——没有辅音丛、没有双元音。
**任何**来源语言的词进来，都要先被压成这个形状。下面先给通用步骤，再给
希腊·拉丁这一实例，最后记录两类**压不进去**的情形。

### 5.1 通用适配步骤

不分来源语言，一律按这五步走：

1. **切音节**：按来源语言的音节切分。
2. **压成 `CV(n)`**：每个音节至多一个辅音在前、一个元音、一个可选韵尾 `n`。
   - **辅音丛：优先删，不要插音**——删是可预测的，插是任意的（理由见 5.4）。
     保留顺序为 **塞音 > 擦音 > 流音**：`st→s`、`pl→p`、`kr→k`、`tr→t`、`ks→s`。
   - **韵尾辅音（非 `n`）一律删除**。
   - **相邻元音各自成音节**，不合并：`lumia` = lu·mi·a。
3. **元音就近归并**到 5 个。音色差异比舌位更显著，所以**圆唇优先保留**：

   | 来源元音 | Lumia |
   | --- | --- |
   | a、ɑ、æ、ʌ、ə | **a** |
   | e、ɛ、eɪ、ø | **e** |
   | i、ɪ、y | **i** |
   | o、ɔ、ɒ、oʊ | **o** |
   | u、ʊ | **u** |

   **长音不区分**：来源语言的长短音对立在这里一律抹平，与同格短音合并
   （Lumia 不区分元音长短，见 §四）。全仓库因此不出现任何长音符号。

4. **削词尾屈折**：`-us / -a / -ēs / -os / -s / -e` 等一律删去。
5. **重音落在首音节**（§四）。来源语言的重音信息**一律丢失**。

### 5.2 希腊·拉丁借词

天文／科幻词主要来自希腊·拉丁语。上面五步在这两门语言上的具体表现：

| 现象 | 规则 | 例 |
| --- | --- | --- |
| 词尾屈折 | 删 | `pulsus → pusa`、`orbis → oba` |
| 辅音丛 | 删其一，保留更显著者；或换位成 CV | `stella → sela`、`planētēs → paneta`、`mikros → miko` |
| 非 `n` 韵尾 | 删 | `kosmos → komo`（删 s） |
| 音节尾的 `r` | 删 | `orbis → oba`、`energeia → enega` |

部分借词为**缩合形式**，不完全遵循上述规则：`era`（aēr）、`sento`（centum，按英式读音）、`kilo`（khilioi）。

例：

| 源词 | Lumia | 说明 |
| --- | --- | --- |
| stella | **sela**（星） | st→s，去 geminate l |
| sol | **sola**（太阳） | +a |
| luna | **luna**（月亮） | 不变 |
| planētēs | **paneta**（行星） | pl→p，去词尾 |
| kosmos | **komo**（宇宙） | 删 s |
| orbis | **oba**（轨道） | 删 r、去 -is |
| vacuus | **vaka**（虚空） | 缩合 |
| pulsus | **pusa**（脉冲） | 删 l、去 -us |
| mikros | **miko**（小） | kr→k |
| makros | **mako**（大） | kr→k |
| energeia | **enega**（能量） | 删 r、缩 ia |
| aēr | **era**（大气） | 缩合 |

> 专名同样遵循此规则：Saturnus → **Satuna**（土星）、Mercurius → **Mekuria**（水星）。

### 5.3 记录：两类压不进去的外来词

Lumia 的词根是**固定的**，而且辅音、元音的数量都多于日耳曼语与斯拉夫语。
这带来一个后果：**大部分外来语无法直接借入**。勉强压进来的词，会按「是否还能反推回源词」
分成两类——这个区别是本语言判断借词是否成立的实测依据。

**第一类：辅音丛被拆开，尚可辨认。**

```
книга  /ˈknʲi.ɡə/   →   kiniga
к н и г а               ki-ni-ga
```

`kn` 是辅音丛，压不成 `CV`，只好在中间插入元音补足。结果 `ки→ki`、`ни→ni`、`га→ga`
一个音节对一个音节——**逐段仍然对得上**，勉强算借进来了。

**第二类：插入的元音与源词原有的元音撞车，词形不再可逆。**

```
table  /ˈteɪ.bl̩/   →   tabele
t a b l e               ta-be-le
```

英语的 `ble` 是**一个音节块**（成音节辅音 /l̩/）。压成 `CV` 时 `bl` 被拆开、
插入 `e` 补足元音，于是 `table` 的五个字母变成了 `tabele` 的六个字母——
**多出来的那个 `e` 与原本就有的那个 `e` 长得一模一样**。

看到 `tabele`，无法判断哪个 `e` 是原有的、哪个是插进去的，也就
**无法把它分析回 `table`**。这是「非法借词」最直接的症候：词形失去了可分析性。

### 5.4 由上述失败得出的三条红线

1. **能删就不插。** 删辅音是可预测的（`st→s` 有唯一答案），插元音是任意的
   （`bl` 里插 `a`／`e`／`i` 都「合法」，于是信息在这里丢失）。
2. **必须插音才成立的外来词，原则上不借**——改用既有词根复合或描写表达。
3. **借词是单向的。** 从源词可以推出 Lumia 词，反过来不行。
   词典里的 `src` 字段（`数据/lumia.json` 的 `lexicon[].src`）就是为此保留的**反向索引**；
   校验要求每一个借词都必须有 `src`，缺了即报错。
